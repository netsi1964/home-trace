# Contributing

Thanks for helping. This project is pre-alpha, so the most useful contributions right now are
feedback on the PRD and small, focused changes.

1. Read `development/PRD.md` and `AGENTS.md` first.
2. Open an issue before large changes, so we agree on scope against the PRD.
3. Keep PRs small and reference the PRD ID, e.g. `feat(PRD-FEAT-004): add same-object prompt`.
4. Add tests, and name the `T##` scenario they cover where relevant.
5. Run lint, type check and tests before pushing.
6. Never commit real household photos, exported archives or provider credentials.
7. Changes to the privacy invariants (PRD-SEC-007) or import validation (PRD-FEAT-009) need a test that proves they still hold.

By contributing you agree that your contribution is licensed under Apache-2.0.
